# 消防站空气呼吸器气瓶充装与检测系统

面向消防救援站装备室的空气呼吸器（SCBA）气瓶全流程管理：装备台账、任务领用 / 紧急借调、
归队检查、充装组批、静置压力复测、背架配套核验、检验到期预警。纯 Python 标准库 + 原生前端，
**零第三方依赖**，SQLite 保存全程事件，本地目录留存检测附件。

## 一条命令启动

```bash
./run.sh            # 默认 http://127.0.0.1:8080
./run.sh --reset    # 清空数据库与附件，重新生成训练数据与样例
PORT=9000 SETTLE_SECONDS=30 ./run.sh   # 自定义端口 / 静置时长（秒）
```

首次启动自动幂等生成：8 名人员（4 种角色）、4 个训练任务、16 只气瓶，并演示
**复测泄漏封存、终压不足转维修、紧急借调、主管报废确认、错误配套拦截、瓶阀损伤维修**等样例。

运行测试：

```bash
python3 -m unittest discover -s tests -p 'test_*.py'   # 41 个用例
```

## 角色与权限（顶栏切换当前操作人）

| 角色 | 可执行操作 |
|---|---|
| 战斗员 | 任务领用本人、扫码归队、背架编号核对 |
| 装备员（充装员） | 归队检查判定、组批/上瓶/充装/复测、维修办结、报废审议 |
| 检验员 | 更新水压试验记录（可与主管一同解封超期瓶） |
| **装备主管** | **解除封存、报废确认**（唯一角色），另可封存 |

## 状态机与关键规则

```
可领用 ──领用/借调──▶ 已领用 ──扫码归队(去重)──▶ 待检查
待检查 ──外观合格 ∧ 瓶阀正常 ∧ 在检验有效期内──▶ 待充装
待充装 ──加入批次接口──▶ 已入批 ──开始──▶ 充装中 ──读终压──▶ 静置中
静置中 ──复测压降≤1.0MPa──▶ 待配套 ──背架编号一致──▶ 可领用
```

- **批次排他**：同一气瓶不能进入两个未结束批次（`active_batch_cyl` 排他锁），中断 / 完成即释放。
- **压力阈值**：额定 30 MPa；终压 < **28.5 MPa（95%）** 判终压不足，退出本批转维修；
  静置后压降 > **1.0 MPa** 判复测泄漏，封存待报废审议。
- **重复归队**：多人 / 多次扫描同一在途气瓶只生成一条归队检查记录，重复扫描仅写审计事件。
- **配套一致性**：重新配套必须扫描背架编号与登记编号一致；错误配套不放行；封存 / 报废瓶不可配套领用。
- **检验周期**：水压试验 36 个月；提前 30 天黄色预警，超期归队检查时封存送检。
- **例外处置**：瓶阀损伤 / 外观不合格→维修；超期未检→封存；终压不足→维修；复测泄漏→封存；
  错误配套→维持待配套；充装中断→未完成瓶退回待充装；紧急借调→登记借调单位。

## 七个视图

装备台账（编号 × 压力紧凑线性仪表行，**无仿真表盘**）· 任务领用 · 归队检查 · 充装组批
（突出每个接口位置与状态）· 压力复测（**38px 大字号并排显示静置初值 / 复测终值**）·
配套核验 · 检验到期；另有全程事件页。视觉：哑光深灰底 + 消防红 + 高可见黄，触控目标 ≥46px。

## 进程内任务与模拟适配器

- `app/reminder.py`：守护线程每 10 秒扫描，生成「静置复测到期」「检验到期 / 超期」提醒
  （按类型+对象去重），顶栏铃铛提示。
- `app/pressure.py`：`MockPressureAdapter` 模拟压力台读数，可故障注入 `LOW_FILL`（26.3 MPa）
  与 `LEAK`（静置掉压 3.5 MPa），读数确定性可复现。
