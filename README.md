# 消防 SCBA · 空气呼吸器气瓶充装与检测系统

面向消防站的空气呼吸器（SCBA）气瓶**归队登记 → 外观检查 → 充装组批 → 静置复测 → 回库配套**
全流程本地系统。零第三方依赖（Python 3 标准库 + SQLite + 原生前端）。

## 一条命令启动

```bash
./start.sh                 # 默认 http://127.0.0.1:8000
PORT=8080 ./start.sh       # 自定义端口
python3 app.py --no-engine # 仅 Web，不启动后台复测/提醒线程
```

首次启动自动：

1. 在 `data/scba.db` 建库（全程事件入库）；
2. 写入训练人员、背架、训练任务、16 个气瓶；
3. 生成演示样例：**复测泄漏（QP-6815）/ 紧急借调（QP-6812）/ 瓶阀报废（QP-6816）/ 超期未检（QP-6814）**；
4. 建立一个进行中的充装批次 `PB-演示-xxx`（含正常 / 泄漏 / 终压不足接口），
   其中泄漏瓶在静置约 12 秒后由**进程内任务自动复测并封存**，界面右上角推送通知。

检测附件保存在本地目录 `data/attachments/`，数据库仅存路径。

## 七个视图

| 视图 | 能力 |
| --- | --- |
| 装备台账 | 编号、所属背架、额定/当前压力（紧凑线性仪表行）、检验有效期、状态；领用/借调/解除封存/报废 |
| 任务领用 | 训练任务与在领人员；扫码归队登记 |
| 归队检查 | 外观/瓶阀/标识勾选，超期自动判封存；检查历史 |
| 充装组批 | 4 个接口位的位置与状态突出展示；组批/开始/完成/中断，模拟压力台故障注入 |
| 压力复测 | 大字号并排显示**初值 → 终值**与压降，合格回库 / 泄漏封存 |
| 配套核验 | 扫描背架编号核对，错误配套拦截；主管可强制改套 |
| 检验到期 | 已超期 / 60 天内到期分列，进程内任务自动生成提醒 |

## 业务规则

- 归队即进入**待检查**；外观（含瓶阀、标识）合格**且**检验在有效期内才能入充装批次。
- **同一气瓶不能进入两个未结束批次**：服务层校验 + SQLite 部分唯一索引
  `uq_position_active` 双重保证；批次中断或复测释放后方可再组批。
- **多人扫描归队只生成一条记录**：部分唯一索引 `uq_return_open` 保证，重复扫描累加
  `dup_scan_count`。
- 充装终压 < 28.5 MPa 判**终压不足**封存；静置复测压降 > 1.0 MPa 判**泄漏**封存；
  压力稳定才回到**可领用**。
- **封存 / 报废状态不可领用、不可配套、不可入批**。
- **解除封存、报废确认仅装备主管**可操作（接口强角色校验）。
- 七类处置：瓶阀损伤、超期未检、终压不足、复测泄漏、错误配套、充装中断、紧急借调，
  均有独立状态流转与事件记录。

## 角色（右上角切换当前操作人）

- 战斗员：任务领用、归队登记、借调归还；
- 充装操作员：外观检查、组批、充装、复测、配套核对；
- 装备主管：解除封存、报废确认、强制改套、借调批准。

## 进程内任务与模拟适配器

- `scba/engine.py`：后台线程每 2 秒扫描——静置复测到期自动读压力台执行；检验到期自动
  生成提醒；通知通过 `/api/notifications` 由前端轮询弹出。
- `scba/adapter.py`：`PressureBenchAdapter` 模拟压力台读数，支持 `leak`（静置掉压）与
  `low`（充装终压不足）故障注入，读数使用确定性伪噪声，保证测试可重复。真实部署时替换为
  硬件驱动，只需实现相同读数接口。

## 测试

```bash
python3 tests.py        # 或 python3 -m unittest -v
```

22 个用例覆盖：**批次排他、压力阈值、重复归队、配套一致性、主管权限**五类必测项，

## 目录结构

```
app.py              HTTP API + 静态文件服务 + 启动入口
start.sh            一条本地启动命令
scba/
  config.py         阈值/角色/状态集中配置
  schema.py         SQLite schema（含排他/去重部分唯一索引）
  service.py        领域服务（全部业务规则与事件）
  repository.py     七视图只读查询
  engine.py         进程内静置复测 / 到期提醒引擎
  adapter.py        模拟压力台适配器
  seed.py           训练数据与泄漏/借调/报废样例
  dates.py errors.py
web/                原生 HTML/CSS/JS 单页（哑光深灰 + 消防红 + 高可见黄）
data/               运行生成：scba.db、attachments/（已 gitignore）
tests.py            规则测试
```

## 主要阈值（`scba/config.py` 可调）

| 参数 | 值 | 含义 |
| --- | --- | --- |
| `RATED_PRESSURE` | 30.0 MPa | 额定压力 |
| `RETURN_LOW_PRESSURE` | 6.0 MPa | 归队余压下限提示 |
| `FILL_FINAL_MIN` | 28.5 MPa | 充装合格终压下限 |
| `RETEST_DROP_LIMIT` | 1.0 MPa | 静置复测允许最大压降 |
| `RETEST_SETTLE_SECONDS` | 12 s | 演示静置时长 |
| `EXPIRY_WARN_DAYS` | 60 天 | 检验到期提前提醒 |
| `INSPECTION_VALID_MONTHS` | 36 月 | 气瓶定期检验周期 |
